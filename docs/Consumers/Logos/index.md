# Logos Consumer

Logos is a downstream library that consumes Cortex as its runtime substrate. It owns LLM workflows,
model-mediated thoughts, cognitive memory, archetype catalogs, and reusable reasoning patterns.

Cortex remains the durable runtime substrate. Logos imports Cortex; Cortex does not import Logos.
