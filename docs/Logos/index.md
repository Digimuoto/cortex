# Logos

Logos is the downstream reasoning library built on Cortex. It owns LLM workflows, model-mediated
thoughts, cognitive memory, archetype catalogs, and reusable reasoning patterns.

Cortex remains the durable runtime substrate. Logos imports Cortex; Cortex does not import Logos.
